# Reference test cases

Owner issues: RA-4 (Rafael: `expected.json` with expected monthly counts, median and anomaly for 2-3 test areas), JA-8 (Jacques: the app must reproduce the same numbers as Python).
Test areas and numbers come from real pipeline outputs, never invented.

## `expected.json`

- **Generated by** `python method/tests/make_expected.py`, after `pipeline/export.py`. It reads only `docs/data/monthly_cells.csv` and `docs/data/metadata.json`, the same files the app reads, so Python and JS start from the same numbers.
- **Rules** (DE-13, DE-16) are written in the file under `rules`:
  - area value = sum of `viirs_eq` over the cells whose centre is inside the rectangle; `null` when the month has no data, never 0;
  - variance = sum of `viirs_eq_var`;
  - median = median of the same calendar month in previous years with data, with `n_years` the number of years used;
  - anomaly = difference and ratio, the ratio only when the median > 0.
- **Test areas**, chosen by a fixed rule:
  - the whole demo area;
  - the 2°×2° square with the highest total of observed months;
  - the one with the lowest non-zero total.
- **Each area lists every month** with `value`, `var`, `median`, `n_years`, `anomaly_diff` and `anomaly_ratio`.
- **JA-8:** the app should reproduce every value within a relative tolerance of 1e-9.
