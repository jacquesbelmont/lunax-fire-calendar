LUNAX Fire Calendar

Monthly NASA FIRMS hotspot detections from harmonized MODIS and VIIRS records. Loading data…

1. Choose an area and a period

Draw a rectangle on the map or enter its coordinates. Counts use detections inside the IBGE boundary of Rondônia.

Map

The selected cells are colored by the month shown in section 3 (same values and colors as the calendar; the color scale tops out at the 95th percentile of the cells). Grey cells have no data, which is not zero fire.

2. Monthly calendar

Each cell is one month. Darker colors mean more hotspots. Grey cells mark months with missing data in the displayed series. The dashed line separates estimated months (above/left) from observed ones. Years marked "prov." contain provisional months from FIRMS near real-time data. Hover for the month status.

3. The latest month compared with its historical median

The data ends at its cut-off date, so the latest month shown here is not the current calendar month.

Light bars: estimated from MODIS. Dark bars: observed by VIIRS. Dashed line: median of the earlier years. Error bars: 90% interval. "prov.": provisional month (FIRMS near real-time data; the value can still change).

4. Downloads

CSV files cover the selected cells and period and include the NASA FIRMS acknowledgment and the data cut-off date.

The hotspot list holds the individual FIRMS detections in the selected cells and period. Count them first to see how many rows the file will have.
