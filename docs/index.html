LUNAX Fire Calendar

Monthly burning activity from harmonized NASA FIRMS MODIS and VIIRS hotspots. Loading data…

1. Choose an area and a period

Draw a rectangle on the map, or type its limits in degrees. Only data inside the study area is available.

Map

2. Monthly calendar

Each cell is one month. Darker colors mean more hotspots. Grey cells have no data: they are never shown as zero fire. The dashed line separates estimated months (above/left) from observed ones. Years marked "prov." contain provisional months (FIRMS near real-time data, replaced later by standard data); the hover text says which.

3. The latest month compared with its historical median

The data ends at its cut-off date, so the latest month shown here is not the current calendar month.

4. Downloads

The files cover the area and period selected above and carry the NASA FIRMS acknowledgment and the data cut-off date.

The hotspot list holds the individual FIRMS detections in the selected cells and period. Count them first to see how many rows the file will have.
